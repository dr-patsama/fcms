# FCMS Design System

## Typography — Cloud Font Family

| Weight | File | Usage |
|--------|------|-------|
| 100 Thin | Cloud-Thin.ttf | Decorative, large display |
| 300 Light | Cloud-Light.ttf | Body text, captions |
| 400 Regular | Cloud-Regular.ttf | Default UI text |
| 600 SemiBold | Cloud-SemiBold.ttf | Labels, nav items, subheadings |
| 700 Bold | Cloud-Bold.ttf | Headings, buttons, emphasis |

Italic variants available for all weights.

## Color Palette

### Ruby Red — Alerts, Danger, Critical values
| Token | Hex | Usage |
|-------|-----|-------|
| `--ruby` | `#E0115F` | Primary danger, critical lab flags |
| `--ruby-light` | `#FF4D8D` | Hover states |
| `--ruby-dark` | `#A00040` | Text on light backgrounds |
| `--ruby-muted` | `#FCE4EE` | Alert backgrounds |

### Emerald Green — Success, Active, Confirmed
| Token | Hex | Usage |
|-------|-----|-------|
| `--emerald` | `#009473` | Primary success, verified status |
| `--emerald-vivid` | `#50C878` | Active indicators, charts |
| `--emerald-dark` | `#006B54` | Text on light backgrounds |
| `--emerald-muted` | `#E0F5EF` | Success alert backgrounds |

### Sapphire Blue — Primary UI, Navigation, Information
| Token | Hex | Usage |
|-------|-----|-------|
| `--sapphire` | `#0F52BA` | Primary buttons, links, focus rings |
| `--sapphire-deep` | `#151667` | Sidebar, header, dark surfaces |
| `--sapphire-light` | `#4A7FD4` | Hover, secondary info |
| `--sapphire-muted` | `#E8EEFA` | Hover rows, info backgrounds |

### Neutrals
| Token | Hex | Usage |
|-------|-----|-------|
| `--white` | `#FFFFFF` | Cards, inputs, modals |
| `--black` | `#000000` | Maximum contrast text |
| `--gray-900` | `#111827` | Primary body text |
| `--gray-500` | `#6B7280` | Secondary text, placeholders |
| `--gray-200` | `#E5E7EB` | Borders, dividers |
| `--gray-50` | `#F9FAFB` | App background |
